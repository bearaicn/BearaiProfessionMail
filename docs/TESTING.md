- 数据初始化、重载保留、客户端隔离、未知专业 API 不清空旧记录。
- 当前角色职业及专业记录，折叠技能列表恢复，稀疏专业 API 返回值。

- [ ] 完全重启客户端，插件列表可见且 TOC 未显示过期，开启 `/console scriptErrors 1` 后登录无 Lua 错误。
- [ ] 登录有主／辅助专业的角色，核对记录；折叠技能标题再刷新，专业仍完整且面板状态恢复，无持续事件循环。
- [ ] 学习／遗忘专业，记录随事件更新；`/reload` 和切换本账号角色后数据保留。
- [ ] 手动添加、修改、重名校验、删除二次确认；不允许修改自动角色；专业选择保存和重新登录后保留。
- [ ] 打开邮箱按钮可见，助手展开／收起／关闭正确，收起再打开数据正确，关闭或走远离开邮箱后全部隐藏。
- [ ] 默认邮箱、其他 UI 插件同时开启时：窗口在旁边，低分辨率和不同 UI 缩放不溢出，原生收件箱和发送页可操作。
- [ ] 同服与跨服目标正确填收件人；取消勾选不填；玩家手改后背包更新不覆盖。
- [ ] 放入亚麻布、矿石、绑定物品及多堆叠材料；与真实背包名称／数量／Tooltip 对照，搜索、分类、分页可用。
- [ ] 新物品未缓存时最终能显示名称，刷新不刷屏、不卡顿、无重复无限 GET_ITEM_INFO_RECEIVED。
- [ ] 自定义材料多专业、全部取消排除、恢复内置，`/reload` 持久化。
- [ ] 原生发送页中，直接从助手拖拽整堆亚麻布至空附件位，无需开背包；附件数量正确，鼠标状态正确。
- [ ] 附件退回、背包整理后列表刷新；拖拽期间槽位变更不取错物品。
- [ ] 鼠标已有物品、锁定、绑定、战斗、满附件栏、邮寄限制均由插件或原生邮箱正确阻止且不丢物品。
- [ ] 关闭邮箱时鼠标正持有材料，由原生 UI 正确处理；助手不自行销毁／清除鼠标物品。
- [ ] 人工核对收件人、附件、邮资并自行发送一封测试邮件，收件角色确认收到；插件没有自行发送。
- [ ] 无限服特有专业／材料和 API 差异：采集诊断和实际物品 ID，补兼容或规则后重测。

不得把 mock 测试、文件复制或无语法错误写成上述勾选项已通过。
