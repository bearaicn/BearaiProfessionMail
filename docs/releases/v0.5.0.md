# 0.5.0 二次分类时光服测试版

新增功能版本，目标时光服3.80.2 /38002，业务共享支持era／forever／titan，本次仅向时光服交付。

- 用途／专业、游戏物品类别、名称／ID搜索取交集；一键添加遵守相同条件。
- 独立物品规则增加“用途未收录（当前背包）”，按ID去重，显示游戏类别，人工补专业后保存用户规则。
- 用户规则和排除最高优先级，类别不猜测专业；信息未加载为待识别，未知子类回退大类。
- 类别实时来自游戏API，不联网，不把类别兜底写进用户规则，无数据库迁移；未复制第三方实现。

26个运行Lua模块语法及三客户端模拟通过，实际类别枚举和新增控件布局待游戏验收。功能完整度与剩余工作见docs/FEATURE-STATUS.md。此记录不代表线上Tag／Release已创建。
