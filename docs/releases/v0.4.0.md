# 0.4.0 开发候选说明 / Development candidate

尚未发布，不代表已经建立 v0.4.0 Tag 或 Release。

物品维护进一步拆为独立规则面板：助手和系统插件设置双入口，查看合并物品列表、按来源及名称／ID 筛选，拖入新增、编辑保存和删除用户规则。用户覆盖标记清晰，同物品优先使用用户数据，空用户规则仍排除专业匹配。角色编辑不再混入物品控件；SavedVariables schema 不变。

材料规则窗口新增物品拖入格子：自动填写 ID、显示名称图标、读取现有专业归属，保留手动输入。只读取身份并取消拾取，不消耗或投放物品。支持异步物品信息刷新。三客户端模拟通过，真实拖放仍待游戏验收。

2026-11-04 数据更新：从 wago.tools 分别取得 Era 1.15.9.70576、Titan 3.80.2.70522、Forever 1.60.1.70755 的 SkillLineAbility 和 SpellReagents，生成 501／763／589 种材料的独立索引。原始快照、SHA-256、整理 JSON 和覆盖统计保留在源码中；安装包只含精简索引与声明。材料名称／ID 搜索在当前筛选内包含匹配，忽略首尾空格。数据库结构不变。本轮数据与搜索仍待游戏内回归。

新增时光服 Classic Titan：本机观察版本 3.80.2.70522，Interface 38002。新增独立 titan 数据域、珠宝加工和铭文、外域／诺森德常见材料规则，以及自适应专业编辑弹层。背包／专业双 API、原生邮箱交互继续共用兼容层。

时光服与无限服均待游戏验证。经典旧世 v0.3.2 的用户验证记录不自动视为 0.4.0 回归通过。正式发布前应根据实际验收更新本文件、中英文 README、CHANGELOG 和状态，再创建新 Tag。
