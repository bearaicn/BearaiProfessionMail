## English

**For World of Warcraft Classic Era 1.15.9 / Interface 11509. In-game functionality has been verified by the user.**

Classic Hardcore uses the same client family; realm restrictions still apply. Retail, Anniversary and other Classic expansions are not targeted. An experimental Forever 1.60.1 / Interface 16001 package is also available; it has not been verified in game.

Download `BearaiProfessionMail-0.3.2-era.zip`, check `SHA256SUMS.txt`, and extract its `BearaiProfessionMail` folder to `_classic_era_/Interface/AddOns/`. Fully restart the game. Automatic source archives are not the lightweight installation package.

For Forever use `BearaiProfessionMail-0.3.2-forever-experimental.zip` under `_forever_/Interface/AddOns/`. `SHA256SUMS-ALL.txt` covers both recommended ZIPs. The original era package and tag are unchanged; the older plain `forever.zip` is superseded by the tagged experimental build.

Includes character/profession management, searchable tables, filters, real bag cells, player-triggered attachment add/remove, settings, branding, bilingual documentation, and MIT licensing. Sending remains manual. The material database is incomplete, accounts do not automatically sync, and other clients and all edge cases are not claimed as verified.
