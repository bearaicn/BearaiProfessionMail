# 熊智专业邮寄助手

**魔兽世界专业材料邮寄助手，支持角色管理、材料筛选与原生邮箱附件操作。**

## 最新发行版：v0.5.6（三客户端测试版）

三个包共用v0.5.6标签，按客户端选择一个安装，校验文件为`SHA256SUMS-ALL.txt`。本次发布标记为测试版，不代表三个客户端均完成全部游戏验收。不面向正式服、周年服或其他资料片。

## 安装

1. 下载适用于 **经典旧世** 的 `BearaiProfessionMail-0.3.2-era.zip`。需要时对照同一发行版的 `SHA256SUMS.txt` 校验文件。
2. 解压，将其中的 **`BearaiProfessionMail` 文件夹**放入经典旧世客户端的 `_classic_era_/Interface/AddOns/`。
3. 完全退出并重新启动游戏，在角色选择界面的插件列表中启用本插件。

无限服请改用 `BearaiProfessionMail-0.3.2-forever-experimental.zip`，安装到对应客户端的 `_forever_/Interface/AddOns/`。这是待游戏验证的实验包，请勿安装到经典旧世。校验两个推荐包请使用 `SHA256SUMS-ALL.txt`；早期 `forever.zip` 是试打包产物，请以 `forever-experimental.zip` 为准。

请使用发行版中的安装 ZIP。平台自动生成的 “Source code” 是完整源码归档，不是精简安装包。

## 使用

1. 打开原生邮箱即显示 **右上方关闭按钮左侧的「专业材料」**。点击入口会切到原生第二标签“发件箱”，并展开／收起助手；若切页失败则提示手动切页，入口不会因此隐藏。
2. 点击角色表格中的一行选择目标；可搜索角色、服务器、职业或专业，也可添加其他角色。
3. 默认按目标角色的专业显示材料。筛选下拉还可选择全部可邮寄候选、全部材料或某个独立专业；名称／物品 ID 搜索可叠加使用。
4. 切到原生 **「发送邮件」** 页。右键未添加的真实背包格子可添加整堆；带勾号的已添加格子只撤回其对应附件。同名不同堆互不撤回。双击未添加堆叠可输入数量；也可直接拖到原生附件栏。
5. 在原生邮箱附件栏查看和撤回指定堆叠；助手不重复显示附件。数量框只针对所点背包堆叠，范围 1 到该堆数量；确认前若槽位或堆叠变化，会拒绝操作。部分数量使用客户端拆分 API，余量留在背包。
6. 核对原生收件人、附件和邮资，**自行点击原生发送按钮**。

需要批量添加时，在下拉框选择“炼金术”“工程学”等具体专业，切到原生发送页，点击材料区下方的 **“一键添加”**。“按角色专业过滤”“全部物品”“全部材料”模式均不启用，哪怕目标角色只学了一个专业。按钮作用于当前搜索结果的全部分页，不限当前 33 格。锁定物品跳过；附件满或操作受阻后停止，不自动发送、拆分或续跑。全部堆叠已加入邮件后，原生附件栏负责查看和撤回。

选择角色时可自动填写收件人，也可关闭此选项；填入后仍可手动修改。材料刷新不会覆盖你修改后的收件人。筛选目标和原生收件人是两个独立状态，请以原生收件人为最终发送依据。

助手支持展开、收起和关闭；关闭邮箱会同步隐藏助手及菜单。可拖动助手顶部空白移动窗口。

| 命令 | 功能 |
| --- | --- |
| `/bpm` | 邮箱打开时切换助手 |
| `/bpm settings` | 打开角色管理设置页 |
| `/bpm diag` | 显示插件版本、客户端和接口信息 |

也可从 **游戏设置 → 插件 → 熊智专业邮寄助手 / BearAI Profession Mail** 进入设置页，无需打开邮箱即可管理角色。

## 角色与账号数据

- 当前登录角色自动记录专业和等级；刷新按钮仅更新当前角色。
- 同一 WoW 账号、同一客户端的角色共享记录。其他本账号角色需要登录后更新，游戏会在退出或 `/reload` 时保存，不是离线实时查询。
- 不同 WoW 账号（包括同战网下的 WoW1／WoW2）不会自动共享；经典旧世与无限服的数据也分开保存。
- 手动记录若与后来登录的角色名称、服务器完全一致，会转为本账号记录，以游戏实际信息更新。
- 手动角色可添加、编辑和删除；自动记录的角色通过登录或刷新更新，不允许手动覆盖。

## 材料筛选与规则

支持旧世九个主要专业，以及烹饪、钓鱼、急救。同一材料可以属于多个专业。

0.4.0 时光服另支持珠宝加工和铭文。扩展规则按客户端隔离；其他客户端不会因此自动启用这两个专业。时光服的服务器特有配方仍需按实际物品 ID 补充。

| 筛选 | 行为 |
| --- | --- |
| 按角色专业过滤（默认） | 使用所选角色已记录的专业 |
| 全部可邮寄物品 | 排除本地已知邮寄限制后的候选物品 |
| 全部材料 | 按材料类别、制造原料标记及已知规则识别 |
| 炼金术、锻造等独立专业 | 不受目标角色已学专业限制 |

切换到另一个角色时，筛选重置为按角色专业，并回到第一页；搜索文字保留。

点击邮箱助手或“游戏设置 → 插件 → 熊智专业邮寄助手”中的 **「物品规则」**，打开独立管理面板；不需要打开邮箱，也不与角色编辑窗口共用。面板左侧按名称／ID 搜索、按来源筛选和滚动查看物品，右侧新增或编辑专业归属。列出的是助手规则与用户规则的合并结果，不限于背包物品，也不是所有游戏物品的百科。

| 来源标记 | 生效方式 |
| --- | --- |
| 助手数据 | 使用插件附带的材料及专业用品归属 |
| 用户数据 | 玩家自行新增，保存在用户 SavedVariables 中 |
| 用户数据（覆盖助手） | 同一物品有双数据，只显示一行，使用用户专业归属，不与助手专业合并 |

修改助手物品并保存时生成用户覆盖，不改写插件内置文件。点击“删除用户规则 / 恢复助手数据”，有助手数据则恢复，没有则从规则列表移除。全不选后保存仍属于用户数据，表示排除专业匹配。既有用户规则继续保留，无须迁移；规则在同账号、同客户端共享，退出游戏或 `/reload` 时落盘。

0.4.0 开发版支持把背包物品拖入规则窗口的物品格子，也可先拾起物品再左击格子。自动填写 ID、显示图标及名称，并载入当前归属；勾选专业后点击保存。此操作只读取物品信息并取消拾取，原物品留在背包，不会添加邮件附件。手动输入 ID 仍可使用，未缓存的物品名称等待客户端返回后刷新。拖入功能已通过三客户端模拟，待游戏内验收。

0.4.0 开发版已改为按客户端构建生成的材料索引，并保留维护者补充与玩家自定义规则。搜索在当前筛选范围内执行：名称和物品 ID 均支持包含匹配，英文不区分大小写，忽略输入首尾空格；搜索不会自动扩大到其他专业或绕过邮寄限制。例如选择“炼金术”后输入 `瓶` 或 `371`，只查找该范围内的匹配物品。

### 数据来源、版本与更新

本次数据取得日期：**2026-11-04**。来源为 [wago.tools](https://wago.tools) 的 Blizzard 客户端 DB2 表：`SkillLineAbility`（专业与法术关联）及 `SpellReagents`（法术消耗物品及数量）。三套客户端分别请求下表完整构建号，没有把旧世或 Wrath 数据当作其他客户端的数据。这里记录的是指定构建的可用快照，不代表所有客户端未来补丁会自动更新。

| 数据集 | 基于客户端完整构建 | 有消耗材料的专业法术关系 | 不同材料 ID | 材料与专业关系 |
| --- | --- | ---: | ---: | ---: |
| 经典旧世／硬核服 era | 1.15.9.70576 / Interface 11509 | 1,570 | 501 | 853 |
| 时光服 titan | 3.80.2.70522 / Interface 38002 | 3,576 | 763 | 1,374 |
| 无限服 forever | 1.60.1.70755 / Interface 16001 | 2,494 | 589 | 1,084 |

统计仅含从源表生成的关系，不包含人工补充；同一法术属于多个专业时分别计数，没有材料消耗的技能不计入。普通服务器共享对应客户端数据，只有实际规则差异才需额外维护。

原始 CSV、来源 URL、取得时间、SHA-256、整理后的关系和逐专业统计都保存在源码仓库中：[来源清单](data-sources/manifest.json)、[覆盖统计](data-sources/coverage.json)、[数据维护说明](data-sources/README.md)。安装包只携带精简 Lua 索引和必要声明，不包含原始 CSV、完整整理 JSON 或第三方参考库；三个生成索引合计约 44 KiB。游戏运行时不联网下载。

**覆盖边界：** 客户端表可能包含尚未开放或无法获取的配方，本版本尚未按服务器实际开放情况剔除；泛用研磨、选矿和非配方用品使用独立人工补充。数据不判断角色已学配方、技能点或实际需求数量，也不是所有物品的百科库。采集专业不一定存在消耗材料，因此草药学、剥皮等筛选为空可能正常。新索引与搜索在三客户端的自动模拟中通过，仍待本次游戏内回归。

开源参考包括 [LibCrafts-1.0](https://github.com/refaim/LibCrafts-1.0) 与 [LibProfessionDB](https://www.curseforge.com/wow/addons/libprofessiondb)，本次未嵌入这些库的代码或数据库。数据权利及研究参考见 [第三方声明](THIRD_PARTY_NOTICES.md)；本项目 MIT 许可不替代第三方游戏内容的权利声明。

已知绑定和任务物品被排除，锁定物品不能拾取。“可邮寄”并不保证任意收件人都能接收，跨服、阵营和服务器规则仍由原生邮箱判定。目前不放宽账号绑定物品，也不支持指定数量拆分。
